# 💰 Mudabbir (Modabr Project)

> **Your personal finance management dashboard to break the paycheck-to-paycheck cycle.**

---

## 🎯 The Problem

You're a hardworking employee earning a decent salary every month. But by the **10th day**, your bank account is nearly empty. 😰

You get your salary on the 1st, feel rich for a few days, spend on everything you want, and then realize you have nothing left to survive the rest of the month. The cycle repeats every single month.

**Enough is enough.** It's time to take control of your finances.

---

## ✨ What Mudabbir Does

Mudabbir helps you:

- 📊 **Track every penny** — Log income and expenses in one place
- 📅 **Plan monthly budgets** — Set spending limits before the month begins
- 🔔 **Visualize spending** — See where your money actually goes with clean charts
- 📈 **Monitor cash flow** — A simple dashboard to stay on top of your finances
- 🎯 **Build discipline** — Break the paycheck-to-paycheck cycle for good

---

## 🚀 Getting Started

No build tools, no frameworks — just open and go.

```bash
# Clone the repository
git clone https://github.com/yourusername/modabr-project.git

# Or simply download the ZIP and extract it

# Open the project
cd modabr-project
```

Then open `index.html` in your browser. That's it!

---

## 🎨 Design Approach

Since this is a **static HTML/CSS** project, the focus is on:

- **Clean, readable layouts** — CSS Grid & Flexbox for the dashboard
- **Visual feedback** — Color-coded categories (income = green, expenses = red, savings = blue)
- **Print-friendly styles** — Use `@media print` for budget reports you can print or save as PDF
- **Responsive design** — Works on desktop, tablet, and mobile using CSS media queries
